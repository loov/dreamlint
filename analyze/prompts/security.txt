Flag any of:
- SQL injection: unparameterized queries, string concatenation in SQL
- SQL column injection: sort or filter columns interpolated from caller-supplied strings. Map a fixed set of named values to SQL fragments instead.
- Command injection: shell commands built from user input, exec calls
- Path traversal: file operations with user-controlled paths without sanitization
- XSS: unescaped output in HTML contexts
- SSRF: user-controlled URLs in HTTP requests
- Insecure deserialization: untrusted data in unmarshal calls
- Unsafe deserialization: language-native serialization (Python pickle, Java Serializable, Go gob with interface{}) across a process or service boundary
- Hardcoded secrets: API keys, passwords, tokens in source
- Weak cryptography: insecure algorithms, weak random sources
- Information disclosure: sensitive data in logs or errors
- IDOR: resource accessed or modified by caller-supplied ID without verifying the caller's permission for that specific resource

Only report actual security issues.
